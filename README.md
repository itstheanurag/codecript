# Codecript: The Ultimate Software Engineering Guide

Codecript is a comprehensive, community-driven collection of technical documents designed to take you from a junior developer to a senior software architect. 

Whether you are preparing for rigorous technical interviews at top-tier companies or just looking to deeply understand backend systems, Codecript provides structured, ELI5-friendly, and highly actionable content.

---

## 🗺️ Guided Learning Paths

The repository contains 14 dense technical directories. If you are not sure where to start, follow the track that best matches your current skill level:

### 🟢 Track 1: The Junior Foundation
*Goal: Master the fundamentals of code execution, data organization, and basic system interactions.*
1.  **[Languages (`content/languages/`)](content/languages/)**: Deep dives into Python and JavaScript internals.
2.  **[Data Structures (`content/ds/`)](content/ds/)**: The building blocks of software.
3.  **[Algorithms (`content/algo/`)](content/algo/)**: Sorting, searching, and complexity analysis (Big-O).
4.  **[Web Fundamentals (`content/fundamentals/`)](content/fundamentals/)**: How the internet actually works.
5.  **[Databases (`content/databases/`)](content/databases/)**: Relational (SQL) vs. NoSQL, Indexing, and Caching.

### 🟡 Track 2: The Mid-Level Engineer
*Goal: Move from writing code that "works" to writing code that is testable, maintainable, and deployable.*
1.  **[API Design (`content/api-design/`)](content/api-design/)**: REST, GraphQL, Webhooks, and OAuth 2.0 Security.
2.  **[Low-Level Design (`content/lld/`)](content/lld/)**: SOLID Principles and Design Patterns (OOP).
3.  **[Testing Methodologies (`content/testing/`)](content/testing/)**: TDD, Mocking, and Load Testing.
4.  **[DevOps & Infrastructure (`content/devops/`)](content/devops/)**: Docker, Kubernetes, and CI/CD pipelines.

### 🔴 Track 3: The Senior Architect
*Goal: Design fault-tolerant, highly concurrent, distributed systems operating at massive scale.*
1.  **[Operating Systems (`content/os/`)](content/os/)**: Virtual Memory, Page Faults, and CPU Scheduling.
2.  **[Concurrency (`content/concurrency/`)](content/concurrency/)**: Mutexes, Deadlocks, Event Loops, and Goroutines.
3.  **[System Design (`content/sys-design/`)](content/sys-design/)**: Core distributed concepts (CAP Theorem, CDNs, Rate Limiting, Consensus Algorithms).
4.  **[Building / Case Studies (`content/building/`)](content/building/)**: Putting it all together (e.g., Designing a URL Shortener or Chat System).
5.  **[Behavioral Prep (`content/behavioral/`)](content/behavioral/)**: Leadership principles and soft-skill assessments.

## Getting Started

To explore the content locally and view the interactive Mermaid.js diagrams:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/itstheanurag/codecript.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. Open your browser to `http://localhost:5173` to browse the interactive versions of the documents.
