# DevOps, Deployment & Infrastructure

Writing code is only half the battle. A senior engineer must understand how that code is packaged, deployed, monitored, and scaled in a production environment. 

This section covers the essential infrastructure concepts that bridge the gap between "it works on my machine" and "it works in production for millions of users."

## What's Inside?

- **[Containerization (Docker)](./001-containerization-docker)**: Understanding isolated environments, images, and layers.
- **[Orchestration (Kubernetes)](./002-orchestration-kubernetes)**: Managing clusters, pods, deployments, and self-healing systems.
- **[CI/CD Pipelines](./003-ci-cd-pipelines)**: Automating testing, integration, and continuous deployment strategies (Blue-Green, Canary).
- **[Infrastructure as Code (IaC)](./004-infrastructure-as-code)**: Treating infrastructure like software with Terraform.
